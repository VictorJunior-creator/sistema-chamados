# Sistema de Chamados

Sistema web full stack desenvolvido como **projeto de aprendizado e prática** de desenvolvimento web.

O projeto tem como objetivo praticar conceitos básicos de frontend, backend, API REST, banco de dados e integração entre diferentes camadas de uma aplicação.

**Atenção:** este projeto **não está finalizado e não deve ser considerado um sistema pronto para produção**. Algumas funcionalidades ainda estão em desenvolvimento, existem limitações, possíveis bugs e partes que precisam ser aprimoradas.

## Tecnologias

### Frontend

* React
* JavaScript
* CSS

### Backend

* Node.js
* Express
* REST API

### Banco de dados

* PostgreSQL
* Supabase

### Ferramentas

* Git
* GitHub
* Postman

## Funcionalidades implementadas

* Criar chamados
* Listar chamados
* Editar chamados
* Alterar status
* Excluir chamados
* Pesquisar chamados
* Filtrar por status
* Dashboard com indicadores
* Validação de formulário
* API REST
* Interface responsiva

> Algumas funcionalidades podem apresentar comportamentos inesperados ou ainda não estar completamente implementadas.

## Arquitetura

```text
React → Express API → PostgreSQL
```

## Objetivos de Aprendizado

O projeto foi criado principalmente para praticar:

* React e desenvolvimento de interfaces
* JavaScript
* Node.js e Express
* Criação e consumo de APIs REST
* Operações CRUD
* PostgreSQL
* Integração entre frontend, backend e banco de dados
* Git e GitHub
* Estruturação de uma aplicação full stack

## Limitações

Por ser um projeto de aprendizado, atualmente ele possui:

* Funcionalidades incompletas
* Possíveis bugs
* Tratamento de erros limitado
* Ausência de algumas boas práticas que ainda estão sendo estudadas
* Recursos que ainda precisam ser melhorados ou implementados
* Não possui a finalidade de ser utilizado em um ambiente real de produção

## Status do Projeto

**Em desenvolvimento / Projeto de estudo**

Este projeto será utilizado para continuar praticando desenvolvimento full stack e poderá receber melhorias, correções e novas funcionalidades conforme meu aprendizado evoluir.
